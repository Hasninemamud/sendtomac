SendToMac
Privacy

From the phone. Onto the Mac.

Download the Mac app and open it. A window opens with the code. Scan it from the phone, then send the file. No account, and the file does not go to a public server.

Download for Mac

Apple silicon. Unzip, then right-click the app and choose Open the first time.

photo.jpg
  1. 01Open SendToMac. A window appears with the code.
  2. 02Scan that code with the Android camera. Same Wi-Fi.
  3. 03Pick the file. It downloads on the other device.
Leave the window open while you send. Received files go to Downloads/SendToMac. The first time, right-click the app and choose Open, then allow incoming connections. A guest Wi-Fi that hides devices from each other will not work. Privacy policy.
