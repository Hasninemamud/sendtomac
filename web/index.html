How it works

Three steps. Same Wi‑Fi.

Install once. Click the menu-bar icon to open. The phone only needs a camera.

01

Install on the Mac

Open the DMG. Run Install SendToMac.command, or drag the app to Applications and right‑click → Open once.

02

Scan the code

Click the menu-bar icon. Scan with the phone on the same Wi‑Fi (not guest Wi‑Fi).

03

Send the file

Pick a photo, drop a file, or write a short note. It lands on the other device.

First open

If macOS blocks the app.

Prefer Install SendToMac.command in the disk image — it copies to Applications and clears the download quarantine. Or right‑click → Open, then allow Local Network when asked.

Built for the desk

A Mac app that stays out of the way.

It lives in the menu bar. The window is small. On your home network the Mac relays the transfer. The file never needs a public upload.

Privacy

Left out on purpose.

SendToMac is for a phone and a Mac on the same Wi‑Fi. Anything that turns it into an account product stays out.

  • No account
  • No analytics
  • No tracking cookies
  • No public file host
  • No sale of data
  • No name or email asked

FAQ

Common questions.

Where do I download it?

Use the latest Mac disk image. Open it and run Install SendToMac.command, or drag SendToMac to Applications and right‑click → Open the first time.

macOS says the app can’t be opened

Right‑click the app → Open, or use System Settings → Privacy & Security → Open Anyway. This is normal for apps that aren’t notarized yet.

Does the file go to a server?

No public upload. On your home Wi‑Fi the Mac keeps a temporary copy only until the other device downloads it, or for about 15 minutes.

How do I open the window?

Click the SendToMac icon in the menu bar. Option⌘ is optional — enable it from the icon’s right‑click menu (may ask for Accessibility once).

Why can’t the phone connect?

Same Wi‑Fi (not guest/isolation). Keep the Mac app running. Allow Local Network / incoming connections if macOS asks. Or join the phone hotspot from the Mac and scan again.

Ready to send from the phone?

Install the Mac app, scan once, and move the file across the room.
