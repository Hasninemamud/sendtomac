SendToMac

From the phone. Onto the Mac.

Same Wi-Fi. Scan the code. Send a photo, a file, or a note. No app, no account, and the file does not go to a public server.

Open on this Mac
  1. 01Open this page on the Mac.
  2. 02Scan the code with the Android camera.
  3. 03Pick the file. It downloads on the other device.
Leave the Mac page open while you send. If macOS asks, allow incoming connections for Python. A guest Wi-Fi that hides devices from each other will not work.
