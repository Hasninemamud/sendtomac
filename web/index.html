Privacy

Left out on purpose.

SendToMac is for a phone and a Mac on the same Wi-Fi. Anything that turns it into an account product stays out.

  • No account
  • No analytics
  • No tracking cookies
  • No public file host
  • No sale of data
  • No name or email asked

FAQ

Common questions.

Where do I download it?

Use the latest Mac disk image. Open it, drag SendToMac to Applications, then right-click and choose Open the first time.

Does the file go to a server?

No public upload. On your home Wi-Fi the Mac keeps a temporary copy only until the other device downloads it, or for about 15 minutes.

Why won’t Option + Command open it?

Open the app once so it is running in the menu bar. After that, hold Option and Command together to show the window.

Why can’t the phone connect?

Both devices need the same Wi-Fi. Guest networks that hide devices from each other will not work. Allow incoming connections the first time macOS asks.

Ready to send from the phone?

Install the Mac app, scan once, and move the file across the room.
